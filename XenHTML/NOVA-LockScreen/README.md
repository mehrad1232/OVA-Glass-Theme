# NOVA Glass Lock Screen Widget

Designed for Xen HTML versions compatible with iOS 12.5.8. Copy this folder to:
`/var/mobile/Library/SBHTML/NOVA-LockScreen`, then enable it in Xen HTML's Lock Screen widget selector.

The widget provides a large live clock, localized date, translucent pearl/ice panels and subtle drifting frost particles. It is an HTML widget, not a native SpringBoard lock-screen replacement. Disable it from Xen HTML if it affects battery or responsiveness.
