# NOVA Glass Complete Edition — iPhone 5s / iOS 12.5.8

## Included components
- SnowBoard icon theme and iPhone 5s wallpapers.
- Separate Messages tweak and preference pane.
- Optional System Experience tweak for selected Lock Screen, Control Center and Phone call surfaces.
- Optional Xen HTML live clock/date widget for Lock Screen.
- Original generated NOVA ringtone, packaged as M4R and installed under /Library/Ringtones.

## Boundaries
This is an iOS 12-era approximation of modern glass styling using UIKit blur, translucent tint and highlights. It is not Apple's native Liquid Glass framework. Lock Screen and Control Center view names are private and can differ across builds. The system tweak uses conservative class-name matching and should be treated as optional until tested on the actual iPhone 5s. The Xen HTML widget requires a separately installed iOS 12-compatible Xen HTML release.
