# NOVA Glass SnowBoard theme

Target: iPhone 5s, iOS 12.5.8, rootful jailbreak, SnowBoard.

- `IconBundles/`: 2x app icons matched by bundle identifier.
- `Bundles/com.apple.preferences-framework/`: iOS 12 Settings glyphs (2x and 3x).
- `Wallpapers/`: six static wallpapers sized for iPhone 5s (640x1136).
- `Artwork-Source/`: high-resolution source PNG artwork.
- `Wallpaper-Preview.html`: browser-only animated preview. It is not installed as a live wallpaper.

Copy this folder to `/Library/Themes/` and enable it in SnowBoard. Some third-party app bundle IDs may differ by installed version; rename the icon file only after confirming the app's actual bundle ID.
