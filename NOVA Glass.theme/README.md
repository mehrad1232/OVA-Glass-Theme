# NOVA Glass Theme

SnowBoard theme package for iOS 12.0+ (tested target: iPhone 5s / iOS 12.5.8).

## Included
- HTML wallpaper with frosted-glass styling
- Daylight glow from 07:00 to 14:00
- Night snowfall outside that window
- Responsive sizing for older iPhones

## Install
1. Download the `NOVA-Glass-Theme-iOS12.zip` artifact from the GitHub Actions run.
2. Extract `NOVA Glass.theme`.
3. Copy the theme folder to `/Library/Themes/` on the jailbroken device.
4. Open SnowBoard settings and enable **NOVA Glass**.
5. Respring if the theme does not apply immediately.

This package is a visual theme. It does not install a ringtone, Control Center tweak, gesture tweak, or system icon pack by itself; those require separate compatible packages.
